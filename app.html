What goes on a tile
Words keeps one word per tile and splits anything longer as it's added. Sentences shows only saved phrases. Both mixes them. Any folder switched to phrases in Edit groups ignores this and keeps full names like "Doc Hudson Best Moments" on one tile.
Tiles on a screenful
Every tile uses the same size of type; each one is only as wide as its word, and the rows fill the width neatly. This number sets how big that type is — pick 6 for big tiles, 12 for smaller ones. More words than that simply carry on below, so nothing is ever hidden.
Hidden folders
